# EvolveAgent: что где лежит и что чем управляется

Одностраничная справка. Метод и разбор результатов — в `EVOLVE_AGENT.md`,
`HANDOFF.md` и `AGENT_REPORT.md`; здесь только карта.

---

## Что это

Фоновый агент, улучшающий код `aimclub/FEDOT`. Тикета ему не дают: дефекты
находятся сами, доказываются падающим тестом, чинятся LLM и принимаются только
через детерминированные гейты. Рантайм FEDOT остаётся CPU и без LLM.

**Кто что делает** — важнее всего остального в этой справке:

| шаг | нужна ли LLM |
|---|---|
| найти дефект | нет |
| доказать его падающим тестом | нет |
| выбрать файл | да, но только среди файлов с уликой |
| написать патч | **да** |
| принять или отвергнуть патч | нет |

## Как найти дефект (без LLM)

```bash
# скан: 79 операций, значения из собственной области поиска FEDOT
python fedotllm/agents/evolve/invariants.py --python $PY --repo $REPO --out scan.json
# находки → падающие тесты, каждый проверен на нетронутом дереве
python fedotllm/agents/evolve/invariants.py --bridge scan.json --repo $REPO --python $PY \
       --out /tmp/fedotllm_invariants.bridge.json
```

Три зонда: **объявлено = использовано**, **граничные значения** из объявленной
области, **детерминизм подмены**. Плюс проверка кэша операций и настраиваемости.
Каждая операция в отдельном процессе, поэтому зависание — это результат.

## Как прогнать агента

```bash
export FEDOTLLM_LLM_API_KEY=sk-or-v1-…
export FEDOTLLM_REPO_PATH=…/fedot            # чекаут FEDOT
export FEDOTLLM_REPO_PYTHON=…/bin/python     # python с fedot + pytest
uv run python examples/evolve_bench.py --runs 5 --override llm.model_name=openai/gpt-5.4-mini
```

**Замеры параллелить только с отдельным чекаутом и отдельными кэшами на арм** —
бенч сбрасывает и патчит дерево, общий чекаут даёт мусор.

## Шесть гейтов приёмки

Патч засчитывается, только если прошёл **все**:

1. **воспроизведение** — тест обязан падать на непропатченном коде;
2. **компиляция + целевой pytest**;
3. **регрессия** — тесты пропатченного модуля и модулей-вызывающих;
4. **CPU AutoML** — короткий `Fedot.fit` работает;
5. **зонд рантайма** — до и после; контрольные случаи обязаны обучаться;
6. **настраиваемость** — если улика говорит «параметр нельзя использовать»,
   операция обязана стать настраиваемой.

Плюс **отпечаток предсказаний** внутри самого теста и **абстенция**: без улики,
существовавшей до патча, прогон завершается отказом до обращения к модели.

Гейты 4–6 и отпечаток появились после патчей, которые прошли все предыдущие и
сделали хуже. Армы, измеренные до них, с более поздними несравнимы.

## Что подаётся в промпт

Для дефекта CatBoost — ≈15 500 знаков, ≈3 900 токенов:

| секция | доля |
|---|---|
| файл по символам: цель и родитель целиком, остальные скелетом | 49% |
| от чего зависит (вниз по графу, один переход, только FEDOT) | 17% |
| улика и готовый падающий тест | 19% |
| где используется (вверх по графу, с кодом) | 7% |
| кто импортирует | 6% |

Правило: **полностью — то, что маленькое; скелет с докстрингами — то, что
большое, всегда с пометкой**. Чужие библиотеки не подаются вовсе.

Замерено: расширение контекста графом **не дало прироста** — 4/5 против 4/5 на
одной модели в одно время. Оно осталось потому, что дешевле по токенам и не
теряет треть файла, а не потому, что помогло.
