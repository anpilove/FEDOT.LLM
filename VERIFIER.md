# Проверяющий: от подозрения к падающему скрипту

`examples/verify_leads.py`. Берёт подозрения читателя
(`triage_lint.py --whole-file`) и отдаёт вердикт интерпретатору, а не модели.

## Три гейта, все решаются запуском

1. **Предсказание.** Модель обязана назвать тип исключения ДО прогона
   (`EXPECT: KeyError`). Падение с другим типом — опровержение, не успех.
   Без этого скрипт с опечаткой засчитывался бы как дефект.
2. **Падение.** Скрипт запускается в чекауте под проверкой
   (`PYTHONPATH=repo`, иначе `import fedot` молча берёт то, что стоит в
   site-packages). Ноль на выходе — подозрение снято.
3. **Публичный вход.** Если скрипт импортировал внутренний модуль, он обязан
   повторить то же падение через `Fedot` / `FedotBuilder` / `Pipeline`.
   Не повторил — находка внутренняя: путь в коде есть, дойти до него нельзя.

Гейт 3 сначала был сделан как суждение модели («достижимо ли это?»). **Не
работает:** три прогона по одним и тем же девяти подозрениям дали 6 «да»,
потом 3 «нет», потом снова 6 «да», причём один отказ ссылался на проверку,
которой в коде нет. Заменён на механику: список публичных модулей сравнивается
точным равенством, а решение выносит повторный запуск. Два прогона подряд —
совпадение до строки.

## Результат на девяти подозрениях

| исход | сколько | что это значит |
|---|---|---|
| подтверждено через публичный вход | **3** | дефект, который увидит пользователь |
| только внутренний путь | 3 | путь есть, легально не дойти |
| опровергнуто | 1 | скрипт отработал без ошибки |
| не проверяется запуском | 2 | модель сама отказалась, скрипта не писала |

Подтверждённые:

| место | что происходит |
|---|---|
| `api/api_utils/params.py:95` | `Fedot(problem='чушь')` → голый `KeyError`. Рядом стоит `except ValueError`, который не сработает никогда: словарь бросает `KeyError`, а `ValueError` в этой ветке не поднимается вовсе |
| `api/main.py:360` | `load()` затем `forecast()` → `AttributeError: 'NoneType' has no attribute 'task'`. `load()` не заполняет `train_data` |
| `api/main.py:397` | `plot_pareto()` без `fit()` → `AttributeError` вместо сообщения |

## Чего гейт стоил

Он снял три находки из шести, которые прошли первые два гейта, **включая одну
мою собственную**: `data_definition.py:177` я вчера подтверждал вызовом
внутренней функции, а через `Fedot.fit(features=42)` библиотека отвечает
внятным `ValueError` с перечислением допустимых типов. Дефекта для пользователя
нет.

Доля отсева — 6 из 9 подозрений читателя. Для сравнения: у линтера спящими
оказались 39 из 40 находок одного правила.

## Запуск

```
FEDOTLLM_LLM_API_KEY=... FEDOTLLM_REPO_PATH=/путь/к/FEDOT \
uv run python examples/verify_leads.py --leads ab_whole.json
```

Флаг `--no-reachability` выключает третий гейт — для замера его вклада.
